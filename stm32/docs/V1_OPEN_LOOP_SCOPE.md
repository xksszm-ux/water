# V1 普通电机开环版本范围

## 目标

先完成一台功能完整、能够稳定运行的四轮机器人。当前版本使用4个普通1:48 TT减速电机，不使用电机编码器，不实现速度PID。

## 电机结构

```text
左前普通电机 + 左后普通电机（并联）→ TB6612 A → 左PWM
右前普通电机 + 右后普通电机（并联）→ TB6612 B → 右PWM
```

MotorTask周期保持10 ms，负责：

- 接收最新左右PWM命令。
- 将输出限制到 `-1000～1000`。
- 正反转换向保护。
- 300 ms通信超时停车。
- 向RobotState发布实际下发的左右PWM。

## 状态与显示

当前版本没有实际轮速反馈：

- OLED不显示RPM，改为显示 `L PWM` 和 `R PWM` 百分比。
- UART状态上传左右有符号PWM千分比。
- CAN ID `0x101` 的Byte2-3、Byte4-5定义为左右有符号PWM千分比，而不是RPM。
- 不估算或伪造实际RPM。

建议OLED内容：

```text
Robot Status
Battery: 4.2V
L PWM: +35%
R PWM: +35%
Distance: 42cm
Mode: BLE
```

## 当前版本仍然实现

- FreeRTOS任务调度。
- TB6612四轮差速开环控制。
- MPU6050、超声波和电池检测。
- OLED显示和W25Q64存储。
- CAN状态与控制通信。
- STM32与ESP32 UART通信。
- ESP32 BLE、LVGL、OTA。
- 低电压电机保护和低功耗管理。

## 延期到下一版

- 四电机编码器采集。
- 实际RPM计算和显示。
- 左右速度双闭环PID。
- 堵转检测和基于轮速的里程估算。

编码器EXTI引脚可以保留，但当前不接线、不计数、不参与控制。

## V1验收标准

- 四个普通电机方向正确，同侧电机并联且转向一致。
- 前进、后退、左转、右转和停车可靠。
- 换向不会造成STM32复位或TB6612异常发热。
- 300 ms通信超时能够关闭电机。
- 低电压时能够禁止电机输出。
- OLED、传感器、存储、CAN、BLE和UART功能按当前版本协议工作。
