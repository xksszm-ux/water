# Step 4 硬件验收清单

在万用表到货前，不连接电机，不启用 `MOTOR_STEP4_TEST_ENABLED`。

## A. 断电检查

- 确认4.5 V正极只接TB6612 VM和AMS输入正极。
- 确认AMS输出3.3 V接STM32 3.3V、TB6612 VCC及3.3 V外设。
- 确认4.5 V正极与3.3 V正极没有直接短接。
- 确认所有GND共地，TB6612所有GND均已连接。
- 确认面包板分段电源轨已用跳线连接。
- 电机和TB6612 VM大电流不得经过面包板长电源轨或细杜邦线；使用短、较粗导线直接从电源分配点连接。
- 暂时断开四个电机和ESP32。

## B. 上电电压检查（仍不接电机）

万用表置直流电压档，黑表笔固定在公共GND：

1. 测AMS输入：应接近4.5 V。
2. 测AMS输出：应接近3.3 V，不能超过STM32允许范围。
3. 测STM32 3.3V引脚：应接近AMS输出。
4. 测TB6612 VM：应接近4.5 V。
5. 测TB6612 VCC：应接近3.3 V。
6. 固件处于待机时测TB6612 STBY：应接近0 V。
7. 观察STM32是否反复复位、芯片或AMS是否异常发热。

任一项不正确，立即断电，不进入电机测试。

## C. 10% PWM轮子悬空测试

1. 用支架托住底盘，保证所有轮子离开桌面且不会碰到导线。
2. 每侧先只接一个电机。
3. 完成A、B两部分后，将 `Application/Services/motor_step4_test.h` 中的
   `MOTOR_STEP4_TEST_ENABLED` 从0改为1，重新编译和烧录。
4. 测试程序依次执行：左正转、停止、左反转、停止、右正转、停止、右反转、停止、双侧正转、最终停止。
5. 所有运动阶段均为10% PWM，每段1秒；停止间隔为0.5秒；序列只运行一次。
6. 方向错误时立即断电，之后修改电机接线或方向反转配置。
7. 测试结束后必须把 `MOTOR_STEP4_TEST_ENABLED` 改回0并重新烧录。

## D. 通过标准

- 左右通道和正反方向均正确。
- 停止阶段可靠进入Standby。
- 换向时STM32不复位，TB6612和AMS无异常发热。
- 停止发送命令超过300 ms后电机可靠关闭。
- 单电机通过后，才能并联同侧第二个电机继续测试。
